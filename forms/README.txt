ONE.COM PHP FORMS

1. Open forms/config.php.
2. Change $TO_EMAIL if needed. Default is campos.santiago138@gmail.com.
3. Upload the entire website folder to one.com, including the forms/ folder.
4. Test with: https://cmwc2027bogota.com/forms/test-mail.php
5. Submit each form from the website.

CSV backups are saved in forms/data/ if $SAVE_CSV is true.
Files created:
- rider-signup.php
- volunteer-signup.php
- sponsor-signup.php
- subscribe.php
- test-mail.php

Security note: do not use these forms to collect payments or sensitive data. Use GoFundMe, Stripe Checkout, PayPal, or Eventbrite for payments.
