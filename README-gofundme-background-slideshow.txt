GOFUNDMЕ BACKGROUND SLIDESHOW

What was added:
- A moving image slideshow behind the GoFundMe donation rectangle.
- The slideshow stays outside/behind the donation card, so the text remains readable.
- The donation card now uses a darker translucent background with a small blur for readability.

Where to edit the slideshow images:
- Open index.html
- Search for: gofundme-bg-slideshow
- Replace the image paths in the five gofundme-bg-slide divs.

Where to edit the animation speed/opacity:
- Open style.css
- Search for: gofundme-bg-slide
- The animation is controlled by @keyframes gofundme-bg-fade.
