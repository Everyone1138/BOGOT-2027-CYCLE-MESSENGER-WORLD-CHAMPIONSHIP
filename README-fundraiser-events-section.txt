FUNDRAISER EVENTS SECTION

What was added:
- A new interactive Fundraiser Events section.
- Filter buttons for All Events, Alleycats, Criteriums, and Other Races.
- Four editable event cards.
- Each event image is wrapped in a clickable link.
- English and Spanish translations were added.

Where to edit event links:
Open index.html and search for: id="fundraiser-events"
Each card has two links you can edit:
1. <a class="fundraiser-image-link" href="#" ...>
2. <a class="fundraiser-card-cta" href="#" ...>

Replace href="#" with your real registration page, Instagram post, GoFundMe event page, or ticket link.

Where to edit images:
Change the <img src="..."> path inside each fundraiser-card. You can use files in images/ or add your own event posters.

If changes do not appear, hard refresh with Ctrl + Shift + R.
