OUR PROUD SPONSORS SECTION

Changes in this version:
- The sponsor banner now spans the full width of the page.
- The EN / ES language switcher works again and remembers the selected language in localStorage.
- The sponsors carousel still pauses on hover.

Where to edit sponsors:
- index.html -> search for: <!-- Our Proud Sponsors -->
- style.css -> search for: /* Sponsors sliding carousel */

How to add another sponsor:
1. Put the new logo file in images/sponsors/
2. Copy one <div class="sponsor-card">...</div> inside BOTH .sponsor-track groups in index.html
3. Change the image file name and alt text

If you do not see changes:
- Save all files
- Re-open index.html or refresh the browser
- Use Ctrl + Shift + R for a hard refresh
