VIDEO GALLERY SECTION

What was added:
- A beige Video Gallery section was added between the sponsors section and the photo gallery.
- Four local MP4 clips were generated from your existing CMWC images so the section works immediately.
- The English/Spanish language switcher updates this section too.

Where to edit video cards:
- index.html -> search for: <!-- Video Gallery Section -->

How to replace a video:
1. Put your real MP4 in the videos/ folder.
2. Change the <source src="videos/...mp4"> value in index.html.
3. Change the poster image if needed.

How to edit English/Spanish text:
- script.js -> search for videosEyebrow, videosTitle, videoTitles, and videoTexts.

If changes do not show:
- Save the file.
- Hard refresh with Ctrl + Shift + R.
