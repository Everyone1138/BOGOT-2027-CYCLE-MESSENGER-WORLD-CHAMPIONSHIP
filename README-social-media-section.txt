SOCIAL MEDIA SECTION

Added:
- New interactive Social Media section with a moving background slideshow.
- Instagram, Discord, Facebook, TikTok, and X/Twitter icons.
- Hover/focus interaction that updates the active channel box.
- Copy handle button.
- English/Spanish text support.

Where to edit links:
Open index.html and search for: <!-- Social Media Section -->
Replace the href values for Instagram, Discord, Facebook, TikTok, and X/Twitter with your real URLs.

Where to change the background images:
Open index.html and search for: social-bg-slideshow
Replace the image src values with any images from the images/ folder.

If icons do not show:
This section uses Font Awesome from a CDN. Make sure you have internet access while testing, or replace the icons with inline SVGs later.
